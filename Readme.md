# 🌎 OLIVERA

> **Um portfólio interativo construído para fugir do convencional.**

🚧 **Em desenvolvimento** — este projeto está sendo desenvolvido de forma incremental e receberá novas funcionalidades, áreas e conteúdos ao longo do tempo.

---

## Sobre o projeto

Este projeto nasceu da ideia de transformar meu portfólio em algo além de uma página com textos, projetos e links.

Em vez de simplesmente apresentar quem eu sou, a proposta é **colocar as pessoas dentro do meu mundo**.

O projeto será desenvolvido como uma **experiência 2D explorável**, onde cada área, personagem, interação e detalhe terá o propósito de apresentar um pouco da minha trajetória como desenvolvedor, meus projetos, habilidades, interesses e personalidade.

---

## 🎮 A ideia

A proposta é unir:

* 🗺️ Exploração
* 🎮 Elementos de jogos
* 📖 Narrativa
* 💻 Desenvolvimento
* 🧩 Easter eggs
* 🎨 Identidade visual

Tudo isso em uma única experiência.

O objetivo é criar algo que seja **profissional, mas que também tenha identidade** e realmente represente quem está por trás do código.

Além da experiência principal, o projeto contará com **segredos, referências e easter eggs** para quem quiser explorar além do caminho convencional.

---

## 🎯 Objetivo

Criar uma experiência que faça a pessoa não apenas **ler sobre mim**, mas **explorar e descobrir quem eu sou através do próprio projeto**.

> **Este não é apenas um portfólio. É uma representação do meu mundo.**
